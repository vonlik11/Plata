# Промпт-радар — Аналитика запросов к ИИ-агентам

Система автоматически структурирует логи запросов пользователей к ИИ-агентам:
- **Загрузка данных** — CSV/JSON через интерфейс или из demo-датасета
- **Классификация** — через LLM API или по ключевым словам (fallback)
- **Поиск сценариев** — TF-IDF + KMeans кластеризация выделяет паттерны использования
- **Саммаризация** — LLM генерирует описание болей, потенциала автоматизации и рекомендации
- **Дашборд** — интерактивный отчёт на Streamlit с рекомендациями для CTO

## Быстрый старт

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Запустите дашборд
python run.py
# Или напрямую:
streamlit run prompt_radar/dashboard.py
```

Дашборд откроется по адресу http://localhost:8501

## Как использовать

### Шаг 1: Загрузка данных
Откройте дашборд и загрузите CSV/JSON файл с логами через кнопку **Upload**.
Или выберите demo-датасет из боковой панели.

### Шаг 2: Настройка LLM (опционально)
В боковой панели включите **LLM API** и укажите:
- **Base URL** — адрес API (OpenAI, vLLM, Ollama, LM Studio)
- **API Key** — ключ доступа
- **Модель** — название модели (gpt-4o-mini, llama3, mistral и т.д.)

### Шаг 3: Анализ
Система автоматически:
1. Классифицирует запросы по категориям
2. Кластеризует в сценарии (use-cases)
3. Генерирует саммари с болями и потенциалом автоматизации
4. Строит дашборд с рекомендациями

## Поддерживаемые форматы данных

| Колонка | Обязательна | Описание |
|---------|-------------|----------|
| request_text / text / query / prompt | **Да** | Текст запроса пользователя |
| timestamp / created_at | Нет | Дата/время |
| user_id / user | Нет | ID пользователя |
| token_count / tokens | Нет | Кол-во токенов |
| response_time_sec | Нет | Время ответа (сек) |
| satisfaction_score / rating | Нет | Оценка 1-5 |
| category / true_category | Нет | Истинная категория |

**JSON** — массив объектов или объект с ключом `logs`/`requests`/`data`.

## Режимы работы

### Режим ключевых слов (по умолчанию)
- Не требует API ключа
- Мгновенная классификация
- Подходит для быстрого анализа

### LLM-режим (при подключении API)
- Семантическая классификация через нейросеть
- Генерация саммари с болями и рекомендациями
- Оценка потенциала автоматизации
- Стратегические инсайты для CTO

## Технические ограничения

- **Нет GPU** — кластеризация на TF-IDF + KMeans (CPU-only)
- **~100k токенов/запрос** — датасет генерирует 50k–150k токенов
- **LLM-классификация** — батчами по 20 запросов для экономии API
- **Fallback** — при ошибке API автоматически переключается на ключевые слова
